# Developer documentation

This directory contains contributor, maintainer, architecture, testing, release, and historical implementation material for CodeXchange.

User-facing installation, configuration, usage, and troubleshooting entry points stay at the repository root:

- `README.md`
- `README.zh-CN.md`
- `TROUBLESHOOTING.md`

Developer-facing entry points in this directory:

- `developer-handbook.md` — contributor, testing, release, and maintenance workflow notes.
- `developer-handbook.zh-CN.md` — Chinese mirror for maintainer workflow notes.
- `provider-adapter-contract.md` — provider adapter implementation contract.
- `provider-live-smoke-evidence.md` — provider live smoke-test evidence.
- `development-log.md` — long-form internal development history.
- `codexchange-hardcut-plan.md` and `codexchange-hardcut-plan.json` — historical migration plan artifacts.

Do not add end-user quickstart or troubleshooting details here unless they are linked from a root user-facing document.
